# Voice2Text — аудио в текст

Браузерное PWA-приложение: запись речи с микрофона и перевод в текст в реальном времени через Web Speech API. Без сервера, без зависимостей.

**[🌐 Открыть приложение](https://gaziza-i.github.io/recorder/)**

## Возможности

- Запись речи с микрофона прямо в браузере
- Перевод в текст в реальном времени (Web Speech API)
- Редактируемый результат — правь текст после распознавания
- Копирование результата в буфер обмена
- Светлая / тёмная тема
- PWA — устанавливается на телефон как приложение

## Стек

- HTML / CSS / Vanilla JS
- Web Speech API (`SpeechRecognition`)
- PWA (`manifest.webmanifest`, Service Worker)

## Ограничения

Web Speech API поддерживается в Chrome, Edge, Safari. Firefox — не поддерживается.
